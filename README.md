# ولت‌یاب بیت‌کوین — ابزار بازیابی کیف پول (اندروید)

اپ اندرویدی برای پیدا کردن **کیف پول‌های گم‌شدهٔ خودتان**: فایل‌های قدیمی والت و عبارت‌های بازیابی (Seed Phrase) را روی دستگاه جستجو می‌کند، اعتبار عبارت‌ها را می‌سنجد و آدرس‌های بیت‌کوین مشتق‌شده از آن‌ها را می‌سازد تا بتوانید کیف پول‌تان را بازیابی کنید.

> ⛔ این اپ **برای پیدا کردن تصادفی کیف پول دیگران نیست** — چنین چیزی از نظر فنی غیرممکن است (فضای کلید ۲ به توان ۲۵۶) و اپ‌هایی که چنین ادعایی دارند کلاهبرداری‌اند. داخل اپ هم یک تب آموزشی همین واقعیت را توضیح می‌دهد.

## امکانات

| تب | کار |
|---|---|
| 🔍 جستجوی فایل‌ها | اسکن محلیِ پوشهٔ انتخابی (با SAF، بدون نیاز به مجوز) برای پیدا کردن: `wallet.dat` بیت‌کوین‌کور (با تشخیص جادوی Berkeley DB)، کیف پول‌های Electrum و MultiBit، فایل‌های `.wallet` / `.key`، کی‌استورهای JSON، فایل‌های حاوی `xprv`/`zprv`، و **عبارت‌های بازیابی ۱۲ تا ۲۴ کلمه‌ای داخل فایل‌های متنی** با تأیید چک‌سام + **ذخیرهٔ گزارش کامل جستجو به فایل** |
| 🔑 عبارت بازیابی | اعتبارسنجی کامل عبارت (فهرست ۲۰۴۸ کلمه‌ای + چک‌سام)، پشتیبانی از گذرواژهٔ اضافی (passphrase)، ساخت آدرس‌ها در هر سه استاندارد: سگویت `bc1…` (BIP-84)، سگویت تودرتو `3…` (BIP-49) و کلاسیک `1…` (BIP-44)، کپی آدرس، استعلام تکی یا **دسته‌جمعی** موجودی از `mempool.space` |
| 🗝️ کلید و آدرس | تبدیل **کلید خصوصی WIF** (با تشخیص نوع فشرده/غیرفشرده و شبکه) به همهٔ آدرس‌های ممکن + استعلام موجودی **هر آدرس** بیت‌کوین |
| 📖 راهنما و امنیت | آموزش کجا گشتن، نکات امنیتی، و هشدار دربارهٔ اپ‌های کلاهبردار |

## حریم خصوصی و امنیت

- جستجوی فایل‌ها و تمام محاسبات رمزنگاری **کاملاً آفلاین و روی دستگاه** انجام می‌شود.
- تنها ارتباط شبکه‌ای: استعلام موجودیِ آدرسِ عمومی (نه عبارت بازیابی) از `mempool.space`، فقط با لمس دکمهٔ «موجودی».
- هیچ داده‌ای جمع‌آوری، ذخیره یا ارسال نمی‌شود.

## پیاده‌سازی فنی

- **Kotlin** + Android Viewها + Material 3، `minSdk 26`، `targetSdk 35`
- پیاده‌سازی خالص و بدون کتابخانهٔ خارجیِ استانداردهای بیت‌کوین در `crypto/`:
  - RIPEMD-160 (پیاده‌سازی کامل)، SHA-256، HMAC-SHA512، PBKDF2، Base58/Base58Check (کدگذاری و کدگشایی)، Bech32
  - منحنی **secp256k1** با `BigInteger` (نقطهٔ فشرده و غیرفشرده)
  - **BIP-32** (derivation کامل)، **BIP-39**، **BIP-44**، **BIP-49** و **BIP-84**، کدگشایی کلید **WIF**
- الگوریتم‌ها با **۱۱۱ تست شامل تمام بردارهای تست رسمی** صحت‌سنجی شده‌اند:
  - هر ۲۴ بردار تست انگلیسی BIP-39 (مرجع Trezor)
  - بردار تست ۱ در BIP-32 در هر ۶ سطح (مقایسهٔ کامل `xprv`/`xpub`)
  - بردارهای تست BIP-84 (آدرس‌ها و کلیدهای عمومی)، آدرس رسمی BIP-49 و آدرس شناخته‌شدهٔ BIP-44
  - بردارهای معروف کلید `k=1` برای WIF (فشرده و غیرفشرده) و round-trip در Base58
  - بردارهای تست استاندارد RIPEMD-160 و Bech32 (BIP-173)

## ساخت پروژه

1. پروژه را در **Android Studio** باز کنید (File → Open).
2. صبر کنید تا همگام‌سازی Gradle تمام شود.
3. روی Run بزنید یا با خط فرمان:

```bash
./gradlew assembleDebug
```

خروجی: `app/build/outputs/apk/debug/app-debug.apk`
